# ACT-06 - Import CSV Flow

## Dùng cho mục

`3.11. Thiết kế module Import CSV`

## Nội dung sơ đồ

Sơ đồ mô tả quy trình import CSV:

- Admin chọn loại dữ liệu cần import.
- Tải file template CSV.
- Điền dữ liệu và upload file.
- Backend parse file CSV.
- Backend validate từng dòng.
- Dòng hợp lệ được lưu vào database.
- Dòng lỗi được ghi nhận vào danh sách lỗi.
- Hệ thống trả kết quả import gồm số dòng thành công và danh sách lỗi.

## Cách đưa vào báo cáo

Đặt hình trong phần mô tả template CSV, upload file và validate từng dòng.
