# ACT-01 - Order Lifecycle

## Dùng cho mục

`3.7. Thiết kế module đơn hàng và thanh toán`

## Nội dung sơ đồ

Sơ đồ mô tả vòng đời đơn hàng:

- Khách checkout giỏ hàng.
- Hệ thống tạo order, order item và payment.
- Hệ thống giữ chỗ tồn kho.
- Với VietQR, khách gửi xác nhận đã chuyển khoản và admin xác nhận thanh toán.
- Admin xác nhận đơn hàng.
- Đơn hàng chuyển qua các trạng thái `CONFIRMED`, `SHIPPING`, `DELIVERED`, `COMPLETED`.
- Nếu đơn bị hủy, hệ thống giải phóng tồn kho đã giữ chỗ.

## Cách đưa vào báo cáo

Đặt hình sau phần mô tả trạng thái đơn hàng.
