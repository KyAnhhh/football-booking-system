# SEQ-04 - JWT Authorized Request

## Dùng cho mục

`3.13. Thiết kế bảo mật`

## Nội dung sơ đồ

Sơ đồ mô tả cách backend xử lý một request cần xác thực:

- Frontend gửi request kèm `Authorization: Bearer <token>`.
- Spring Security chặn request.
- JWT được decode và verify chữ ký.
- Hệ thống kiểm tra token có bị thu hồi trong Redis không.
- Hệ thống lấy role trong token và kiểm tra quyền truy cập endpoint.
- Nếu hợp lệ, request được chuyển đến controller.
- Nếu không hợp lệ, trả 401 hoặc 403.

## Cách đưa vào báo cáo

Đặt hình ở phần mô tả bảo mật bằng JWT và phân quyền theo role.
