# 3.2 - Class Diagram theo tầng

## Dùng cho mục

`3.2. Thiết kế Class Diagram tổng quan`

## Nội dung sơ đồ

Sơ đồ mô tả cách hệ thống được chia theo tầng:

- Tầng giao diện: React Page và Frontend Service.
- Tầng API: Controller, Request DTO, Response DTO.
- Tầng nghiệp vụ: UserService, BookingService, OrderService, PaymentService, InventoryService.
- Tầng dữ liệu: Repository, Entity và MySQL.

## Cách đưa vào báo cáo

Đặt hình này sau class diagram tổng quan để giải thích cách dữ liệu đi qua các tầng trong backend/frontend.
