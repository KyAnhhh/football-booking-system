# SEQ-01 - Login Authentication

## Dùng cho mục

`3.4. Thiết kế module xác thực và phân quyền`

## Nội dung sơ đồ

Sơ đồ mô tả quy trình đăng nhập:

- Người dùng nhập username và password.
- Frontend gọi `POST /api/auth/login`.
- Backend tìm user trong database.
- Backend kiểm tra mật khẩu bằng BCrypt.
- Nếu hợp lệ, hệ thống tạo access token và refresh token.
- Frontend lưu token và điều hướng người dùng theo vai trò.
- Nếu sai thông tin, backend trả lỗi 401.

## Cách đưa vào báo cáo

Đặt hình sau đoạn mô tả login, JWT access token và refresh token.
