# ARCH-02 - API Data Exchange

## Dùng cho mục

`3.12. Thiết kế API và mô hình trao đổi dữ liệu`

## Nội dung sơ đồ

Sơ đồ mô tả luồng trao đổi dữ liệu từ frontend đến backend:

- React Page gọi frontend service.
- Service gửi HTTP request kèm JWT.
- Controller nhận request và bind DTO.
- Service layer xử lý nghiệp vụ.
- Repository truy xuất MySQL.
- Mapper chuyển entity sang response DTO.
- Controller trả JSON response cho frontend.
- GlobalExceptionHandler xử lý lỗi tập trung.

## Cách đưa vào báo cáo

Đặt hình này trong phần giải thích RESTful API, DTO request/response và luồng dữ liệu giữa các tầng.
