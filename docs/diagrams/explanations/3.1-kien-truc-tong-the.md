# ARCH-01 - Overall Architecture

## Dùng cho mục

`3.1. Kiến trúc tổng thể`

## Nội dung sơ đồ

Sơ đồ mô tả kiến trúc tổng thể của hệ thống gồm:

- React SPA chạy trên trình duyệt.
- Spring Boot REST API xử lý nghiệp vụ.
- Spring Security kiểm tra JWT và phân quyền.
- MySQL lưu dữ liệu nghiệp vụ.
- Redis lưu token đã thu hồi.
- Cloudinary lưu hình ảnh.
- SMTP Mail gửi email đặt lại mật khẩu.
- QR Code Service tạo QR/VietQR.

## Cách đưa vào báo cáo

Đặt hình này ngay sau đoạn mô tả kiến trúc client-server ở mục 3.1.
